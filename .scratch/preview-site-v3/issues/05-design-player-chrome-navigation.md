# Design player chrome and navigation

## Parent

[PRD](../PRD.md) — Preview site v3

## What to build

Produce mockups or annotated wireframes for the Preview player chrome and site navigation, sufficient to implement without further product questions. Decisions needed:

1. **Home navigation** — how visitors switch between the player home, About, and Participants (and later Tags, Map) on a **non-scrollable** full-viewport home page (icon bar, text tabs, etc.)
2. **Subtitle language picker placement** — where the Subtitle language control sits in the player chrome (transport row, filter row, near captions, etc.)
3. **Participants grid labels** — show Participant name under each thumbnail, or image-only

Deliverable: design artifacts linked or stored in-repo, referenced by implementation issues 06, 07, and 08.
